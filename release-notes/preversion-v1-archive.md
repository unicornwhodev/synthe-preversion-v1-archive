# Synthé préversion v1 — archive

This frozen release gathers the last published `v1.0.2` packages for the
Percussion, Rare and Orchestral UWdeVST collections before the next collection
generation.

Included for each collection:

- Windows x64 package with Standalone and VST3 formats;
- validated Linux x86_64 archive with Standalone and VST3 formats;
- macOS source/builder archive.

The macOS archives are build packages, not compiled, signed or notarized macOS
binaries. Package SHA-256 values are recorded in `SHA256SUMS.txt` and
`ARCHIVE_MANIFEST.md` in the repository.

Piano, Bass, Guitar and Drum are not part of this archive. Drum remains under
active development and outside the migration scope.
